### 1.1 核心目标（一句话）
> 把 A4 生成的正常模版参数与系统事件日志存入**存储介质**（片内 Flash 或外挂 SPI2 W25Q64，**介质选择待定（需人确认）**），**掉电不丢失、上电自动加载**。

### 1.3 任务边界

| 外部依赖 | A4 模版参数（A4-01 PC 端 K-means K=16 生成的正常模版，事实包 §3.6）、Flash 扇区规划（待定需人确认） |

### 1.4 关键参数（事实包 §3，禁止自造）
- **存储介质（待定需人确认）**：两种候选，开跑前必须选定：
  - ① STM32 **片内 Flash**（HAL `HAL_FLASH_Program/Erase`，扇区规划需人确认）；
  - ② **外挂 SPI2 W25Q64**（`pin_config.h` 已定义：`FLASH_SPI=SPI2`、8MB、扇区 4096、页 256，注释"复用 pointer-desk 已验证引脚"；接线 SCK=PB10/MOSI=PC3/MISO=PC2/CS=PB12）。
  - **选择权在人，本 FEAT 不擅自决定**；选定后按对应接口实现。
- 模版参数来源：**A4-01** PC 端 K-means（K=16）生成的正常模版（事实包 §3.6）；参数具体格式/字节数：**待定（需人确认，依赖 A4 输出格式）**。
- 事件日志来源：如 **A4-03** 连续 30 帧异常报警 / 连续 60 帧正常解除等事件（事实包 §3.6）；日志条目结构/数量上限：**待定（需人确认）**。

- 数据完整性：魔数 / 版本 / 校验（**校验算法待定需人确认**；可参考 A5-02 CRC16 思路，但**不得直接套用**，需人确认后定稿）。

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 读回全 0xFF | 从未写入 / 地址错 / 擦除后未写 / 介质选择或接线错（W25Q64 未接对） | 确认存储介质与扇区规划（待定）；片内先擦除再编程；W25Q64 查 SPI2 接线（SCK=PB10/MOSI=PC3/MISO=PC2/CS=PB12） |
| 写失败/返回错误 | 未擦除 / 地址越界 / 对齐问题 | 检查擦除流程与地址范围（待定） |
| 重启后参数丢失 | 写未完成即掉电 / 校验失败回退默认 | 查写入完成确认（HAL 返回值）+ 掉电时序；记录回退事件 |
| 参数损坏但无提示 | 无校验 | 加魔数 + 校验（方案待定需人确认） |
| 日志区越界写坏参数区 | 两区布局重叠 | 确认地址不重叠且留余量（待定） |
| 擦写次数超限后失效 | 日志频繁写同一扇区 | 环形多扇区/磨损均衡（方案待定需人确认） |
