### 3.1 上电前检查（红线：全程断电，先拔电源再动线；重点核对三极管极性）
1. **三极管极性核对（接线前必做）**：确认三极管型号与引脚排布（丝印/数据手册），NPN 与 PNP 接法相反，**接反不响且可能损坏驱动管**。具体接法按电路设计（待定（需人确认）），务必与原理图逐脚核对：基极 B（经限流电阻）→ PE6、发射极 E / 集电极 C 与蜂鸣器供电方向一致。
2. 蜂鸣器接线：供电端与地按三极管开关电路接好；**先不插电**。
3. 万用表**电阻档**量 PE6 对 GND → 应 **>100Ω**；接近 0Ω = 短路，回查接线。
4. 供电红线：只准电脑 USB / 非快充 5V 适配器；**严禁手机快充头**（烧板事故根因，见 A1-01）。
5. 万用表直流电压档：量 5V 引脚 → 期望 **4.8 ~ 5.2V**；量 3.3V 引脚 → 期望 **3.2 ~ 3.4V**（记录数值：___V / ___V）；不在范围 → 断电换电源，禁止继续。

### 3.2 上电基线观察（正常态）
1. 插电，正常态（无异常标志）：蜂鸣器应**静音**。
2. 若一上电就响 → 查 §3.4（有效电平反 / 标志误触发 / 三极管常通）。

### 3.3 异常断续报警验证（阶段 4 执行）
1. 记录异常标志触发方式：___（接口待定（需人确认），按阶段 1 确认结果填写）。
2. 触发**异常标志** → 蜂鸣器**断续报警**：记录"响 ___ 秒 / 停 ___ 秒"（期望节奏：待定（需人确认））。
3. 恢复正常（清除标志）→ 蜂鸣器**静音**（记录：静音 是/否）。
4. 结论记录：静音/断续报警实测是否符合预期（是/否），未通过项写进执行日志。

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 蜂鸣器完全不响 | 三极管极性接反 / 有效电平错 / 未触发标志 | 断电核对三极管极性（§3.1）；查驱动电平；确认标志在触发 |
| 一上电就响 | 有效电平反 / 标志误触发 / 三极管常通 | 查默认电平与标志；查三极管是否击穿/接错 |
| 一直响不停 | 断续逻辑未生效 / 标志未清除 | 查断续计时逻辑；确认标志被清除 |
| 断续节奏不对 | 响/停参数未按设计 | 按阶段 2 确认的节奏重配（参数待定（需人确认）） |
| 声音很小/发闷 | 有源/无源判断错 / 供电不足 | 确认蜂鸣器类型与驱动方式（待定（需人确认）） |
| 烧录失败 | ST-Link 四线/驱动 | 查 SWDIO/SWCLK/GND/3.3V；兜底 `firmware\flash_isp.bat`（HANDOFF §4.3） |
| 编译报错 | 工具链/路径问题 | 截图报错，查 `firmware\build.sh` 或 CI |
