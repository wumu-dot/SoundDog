### 3.3 解析负例与边界（阶段 4 执行）
对同一合法帧，逐项篡改后喂入解析器，期望**全部被拒绝**（丢弃，不误判为合法）：
| 篡改方式 | 期望 | 记录（拒绝=✓ / 误收=✗） |
|---------|------|------------------------|
| 帧头 0xA5 改错 | 拒绝 | ☐ |
| 负载 1 字节改错 | 拒绝（CRC 错） | ☐ |
| CRC16 字节改错 | 拒绝（CRC 错） | ☐ |
| 帧尾 0x5A 改错 | 拒绝 | ☐ |
| 空负载帧 | 按帧定义接受或拒绝（记录结论） | ☐ |
| 负载超上限帧 | 拒绝（长度超限） | ☐ |

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 合法帧往返不一致 | 打包/解析字段顺序错 | 对照 §3.1 帧格式逐字段核对 |
| CRC 校验全部失败 | 多项式/初值/位序/字节序与收发双方不一致 | 核对 §3.1 记录值与两端实现一致 |
| 帧头帧尾识别错 | 帧格式双方定义不一致 | 核对 §3.1；确认未确认项已补齐 |
| 解析器误收篡改帧 | 未校验帧尾/CRC/长度 | 退回阶段 3，补全校验路径 |
| 半双工下收发冲突 | 发完未等回复就再发 | 发完一帧等对方回复或超时后再发（A5-04 细化） |
