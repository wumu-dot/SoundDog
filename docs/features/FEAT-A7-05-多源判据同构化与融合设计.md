## 0. 三源核对（R27）—— 结论与证据

| # | 待验设计点 | 源① 标准 / 权威 | 源③ 交叉验证 | 判定 |
|---|---|---|---|---|
| **V-1** | 加速度必须积分成**速度 RMS** 才能对标标准 | ISO 20816（取代 ISO 10816）：评价量 = **振动速度均方根**；测加速度须积分后再与限值比较 | 频域积分（FFT→每行 ÷ 2πf → IFFT）为现代分析仪标准做法，无累积误差；时域积分有漂移，仅在无法频域时使用 | ✅ **成立** |
| **V-2** | 积分前要高通、频带取 **10~1000 Hz** | ISO 10816/20816 规定消除 **10 Hz 以下**分量 | 多处一致：带通 10~1000 Hz 后再算 RMS | ✅ **成立** |
| **V-3** | 速度 RMS 能测到轴承故障 | — | ❌ **不能**：轴承故障在 **500 Hz~10 kHz**，且在速度谱里被 `1/ω` 压低（"在速度谱里权重很小"）；须用**加速度包络解调** | ⛔ **不能，须写明** |
| **V-4** | 温度可用"温升"作判据 | GB/T 755-2019 / IEC 60034-1：温升 = **绕组/轴承本体温度 − 环境温度**，轴承温升 ≤40 K、轴承温度 ≤95 ℃；须**预埋热电偶或电阻法** | GB/T 1032：环境温度用于**温升修正**，不是判据本身 | ⛔ **不成立**（SHT30 测空气，非本体）→ 改为**修正项** |
| **V-5** | 三级状态（正常/预警/报警） | ISO 10816 四区 A/B/C/D + ALARM 设在 B/C 界、TRIP 设在 C/D 界 | 工业实践普遍用黄/橙/红三级 | ✅ **成立** |
| **V-6** | 多通道联合判断（分诊）是工业做法 | — | 行业实践：低频速度超限 **AND** 高频包络超限才跳机；仅一路超限只预警并给方向 | ✅ **成立**（属实践，非标准，须标注） |
| **V-7** | ISO 分区可直接引用 | ISO 10816-3 适用 **>15 kW** 机组；`15 kW or less (outside)` | 小功率设备只能用"相对基线"评价 | ⚠️ **有条件**，取决于实验设备功率 |

### 0.1 🔴 本文基于三源做出的**设计修正**

| 原设想（2026-11-01 早） | 三源结论 | 修正为 |
|---|---|---|
| 温度用「温升速率」作独立判据 | 测的是空气，非本体，不符合温升定义 | **温度改为「环境补偿 + 环境异常提示」**，不出独立报警 |
| 振动输出 mg | 标准用速度 RMS | **频域积分成 mm/s** 后输出 |

## 2. 目标：三模块同构

### 2.1 统一输出契约

每个模块都输出**同一种结构**：

```c
typedef struct {
    uint8_t  level;   /* 0=正常 1=预警 2=报警 */
    uint8_t  score;   /* 0~100 异常度 */
    uint16_t raw;     /* 原始量（供显示/调试）*/
    uint8_t  valid;   /* 0=数据无效/未就绪 */
} mod_result_t;
```

### 2.2 三模块的角色（**不是三个都出判据**）

| 模块 | 角色 | 判据来源 | 输出 |
|---|---|---|---|
| **声学** | **主判据** | 自建：MFCC 距离 vs 阈值 | `level` + `score` |
| **振动** | **主判据** | ISO 20816 速度 RMS（>15 kW 对标分区；否则自建基线） | `level` + `score` |
| **温度** | **辅助 / 修正** | 不单独判故障；提供环境温度用于**基线修正**；环境异常时给提示 | `修正系数` + `环境提示` |

⚠️ 这一条必须写进论文：**"三模块"≠"三个都判故障"**。温度是条件量，不是判据量——这是由 GB/T 755 的温升定义决定的，不是我们偷懒。

## 3. 各模块设计

### 3.1 声学（已有，需补数据）

| 项 | 现状 | 本次要补 |
|---|---|---|
| 特征 | MFCC 13 维，帧长 400 / 移 160 | 不改 |
| 判据 | `d > th` → 防抖 → 报警计数 | 不改 |
| 异常度 | 无 | `s1 = min(100, 100·d/th)` |
| **误报率数据** | ❌ **从来没有测过** | **必补**：安静环境连续 1 h，统计误报次数 |

### 3.2 振动（新建，细节见 FEAT-A7-04）

| 步 | 内容 | 依据 |
|---|---|---|
| 采集 | I2C2（PF1/PF0）读 `0x3B` 起 6 字节，**采样 ≥ 500 Hz** | 需覆盖 1×~3× 转频 |
| 积分 | **频域积分**：FFT → 每行 ÷ 2πf → IFFT，得速度 | V-1 |
| 滤波 | 高通 10 Hz / 带通 10~1000 Hz | V-2 |
| 统计 | 1 s 窗口速度 RMS（mm/s） | V-1 |
| 判据 | >15 kW：按 ISO 分区（1.4/2.8/4.5）；否则按**自建基线 ×N** | V-5、V-7 |
| 异常度 | `s2` = 按分区/倍数线性映射到 0~100 | — |
| ⛔ 不做 | 轴承故障、频谱诊断 | V-3 |

### 3.3 温度（改角色）

| 项 | 做法 |
|---|---|
| 判据 | ❌ **不单独判故障** |
| 用途 1 | **基线修正**：环境温度偏离标定时温度 ≥ ΔT，则声/振阈值按比例放宽（避免夏天误报） |
| 用途 2 | **环境异常提示**：环境温度持续上升（如电箱通风不良）→ 单独提示，不并入设备报警 |
| 输出 | 修正系数 `k ∈ [0.9, 1.2]` + 环境提示 flag |

> ⚠️ 若将来要真正测温升，必须加**贴片式传感器（PT100/DS18B20）贴在轴承座或机壳**，SHT30 做不到。这属硬件升级，本文不覆盖。

## 4. 融合与分诊

### 4.1 融合规则（简单可解释，不做黑箱）

```
S = max(s1, s2)            // 取最严重的一路（保守）
level = 0/1/2              // 由 S 的区间决定
主导通道 = argmax(s1, s2)
```

**为什么用 max 而不是加权平均**：报警系统的原则是"任一路严重即报警"，加权平均会让某一路的高值被另一路的低值冲淡 —— 这在安全场景是错的。

### 4.2 分诊输出（给运维的一句话）

| 情形 | 输出 |
|---|---|
| 全正常 | `正常` |
| 只有 s1 高 | `预警｜声学主导 → 查皮带/润滑/异物` |
| 只有 s2 高 | `预警｜振动主导 → 查地脚/配重/联轴器` |
| s1、s2 都高 | `报警｜声振同异常 → 停机检查` |
| 环境温度异常 | `提示｜安装环境温度偏高`（不计入设备报警） |

> 这套"分诊"逻辑的依据是 V-6（工业双通道联合判断实践），**不是标准条文**，论文中须标注。

## 5. 验证方法（这是本文最要紧的一节）

### 5.1 必须产出的四组数据

| # | 数据 | 怎么测 | 用途 |
|---|---|---|---|
| **M-1** | 声学**误报率** | 安静环境连续 1 h（约 3600 帧判决） | 支撑"能用"的最基本证据 |
| **M-2** | 振动**基线方差** | 静止 10 min，统计 mm/s 的均值与 σ | 定自建基线的阈值 |
| **M-3** | **单源 vs 融合**对比 | 造故障（不平衡/松动）3 次，分别统计单源报警与融合报警 | **论文核心结果** |
| **M-4** | 分诊正确率 | 三次故障中，主导通道是否指向了真实施加的故障 | 支撑"分诊有用" |

### 5.2 故障制造（可重复）

| 故障 | 制造方法 | 预期主导通道 |
|---|---|---|
| 不平衡 | 风扇/联轴器**贴配重** | 振动（1× 增大） |
| 松动 | **松一个地脚螺栓** | 振动（亚谐波） |
| 声学异常 | 摩擦/异物（如轻触旋转件、放异物） | 声学 |

### 5.3 判据（通过线）

| # | 通过线 |
|---|---|
| AC-1 | 声学误报率 ≤ 1 次/h（安静环境） |
| AC-2 | 振动静止时 RMS 波动 σ ≤ 0.2 mm/s |
| AC-3 | 三次故障中，至少 2 次能在 10 s 内产生报警 |
| AC-4 | 融合报警**不晚于**单源报警超过 5 s（不能因融合而迟钝） |
| AC-5 | 分诊主导通道 3 次中至少 2 次正确 |
| AC-6 | 不影响既有功能（OLED/Modbus/云端联跑 30 min 零错误） |
| AC-7 | 无测试遗留 |

## 7. 能力边界（必须写进论文，不能含糊）

| 能 | 不能 |
|---|---|
| 判断"设备是否偏离正常" | 判断"是哪种故障、哪个部件" |
| 输出振动烈度（mm/s），>15 kW 可对标 ISO 分区 | 测轴承早期故障（速度谱里被压低，见 V-3） |
| 给出"哪一路主导"的分诊建议 | 给出故障频率证据 |
| 环境温度补偿，降低季节误报 | 测设备本体温升（SHT30 做不到，见 V-4） |
