## 1. 总体目标与硬边界

### 1.1 核心目标（一句话）

> 对 A3-02 的 32 维 Mel 能量取 Log 后做 DCT-II（N=32），取前 13 维输出 MFCC 特征向量，供 A3-04 验证与 A4 模版比对使用。

### 1.4 关键参数（事实包 §3.6 A3-03，禁止自造）

* 输入：A3-02 的 **32 维 Mel 能量**。

* **Log 能量**：对 32 维 Mel 能量取对数（**底数：已定（阶段 1 官方裁决）——自然对数 ln**，官方 `arm_vlog_f32` 同口径，全流程与 CMSIS-DSP/TF 一致）。

- **DCT-II**（标准定义）：`X_k = Σ_{n=0}^{N-1} x_n · cos(π·k·(2n+1)/(2N))`，N=32。

- 输出：**取前 13 维 MFCC**（事实包：取前 13 维；即 k=0..12）。

- **归一化系数 / 是否正交归一：已定（阶段 1 官方裁决）——官方 "almost orthogonal" 口径**：统一因子 `sqrt(2/N)=sqrt(2/32)=0.25`，**无 k=0 行 1/sqrt(2) 特殊化**（k=0 行范数²=2，TF 文档 "HTK's scaling...almost orthogonal" 原话的数学含义；Issue #54 维护者实测 CMSIS 与 TF 逐值一致背书）。

- 采样率 **Fs = 16kHz**（A1-04 核实后为准）。

- 输出维度：**13 维 MFCC 向量**。

#### 一、已确认决策（人确认"都进行"，2026-08-30）

| 决策项    | 定稿                                                                                                                    | 来源/理由                                                                                                              |
| ------ | --------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Log 底数 | **ln**（`arm_vlog_f32`，M4F 无 MVE/NEON 走 libm logf）                                                                     | 官方 L135 同口径；与 TF/官方零转换，A4 模版生成直接复用（ln↔log10 仅整体常数差）                                                                |
| ε 偏移   | **+1e-6**（官方 L134 `arm_offset_f32` 字面值）                                                                               | 官方字面值；A3-02 立项输入同口径                                                                                                |
| DCT 形式 | **直接生成 13×32 矩阵**（非先算 32 维再截取），`cos(iπ(j+0.5)/32)·0.25` 行主序                                                           | 官方 mfccdata.py dctMatrix() 同构（NB 输出即矩阵行数）；416 vs 1024 MAC 省 60%，数学严格等价（DCT 线性）                                     |
| 矩阵乘实现  | **自写 416-MAC 双层循环**（对策 B）                                                                                             | `arm_mat_vec_mult_f32` 未 vendored（MatrixFunctions 目录整个缺失）；补 vendor 有依赖链风险（A3-02 坑 4 翻版）；自写 \~10 行 + PC diff=0 判据兜底 |
| 音量归一化  | **log 前对 32 维 Mel 做 absmax 归一化**（Mel 域，非官方时域位置）                                                                       | 音量鲁棒是 A4 刚需（同一声源不同响度 → 特征恒定）；代价：**与官方 TF 实测值不可逐值对照**（官方在 FFT 前时域归一化，我们帧已加窗不能照搬位置），验证判据改为"PC 复刻同公式 vs 固件输出自洽"       |
| 打印格式   | `MFCC13 c=<c0>,<c1>,...,<c12>`（×100 整数定标 `%ld`，BANDS/MEL 逗号风格，1s 节流；实现期修正：前缀加 13 区别 A3-01 的 `MFCC f=...` 统计行，防前缀过滤撞行） | newlib-nano 无 %f；c0 静音约 -11000（ln(1e-6)×32×0.25×100），`%ld` 位数足够                                                    |

#### 二、数据流

```
specTask: mfcc_feed() 出帧 → mel_frame_cb(freertos.c:183)
  ├→ mel_process(frame400, s_mel_vals)          [A3-02，已有]
  └→ mfcc_dct_process(s_mel_vals, s_mfcc13)     [本 FEAT 新增串接]
         内部: absmax 归一化 → +1e-6 → ln → 13×32 矩阵乘 → out13
打印: SpecTask 主循环 1s 节流 MFCC 行（与 MEL 行并列）
```

#### 三、接口

```c
/* BSP/mfcc_dct.h（目录按 mel.c 先例：BSP/，非子FEAT模板字面 Src/dsp/） */
#define MFCC_DCT_IN  32u   /* A3-02 Mel 维度 */
#define MFCC_DCT_OUT 13u   /* 事实包：前 13 维 */
int mfcc_dct_process(const float32_t *mel32, float32_t *mfcc13);
/* 纯函数：表 const 无状态 → 无 init（对比 mel_init：无 FFT 实例需求）
 * 返回 0 成功；-1 参数空。非重入（内部静态缓冲）；调用者仅 specTask。 */
```

#### 四、机制

1. **absmax 归一化**：32 维求 max → `mel[i]/=max`。**除零保护**：`max ≤ 1e-12` 时跳过归一化直接走 +1e-6 地板（静音帧全 0 → ln(1e-6)=-13.8 常数行，输出确定值非 NaN）。
2. **偏移+取对数**：`arm_offset_f32(+1e-6)` + `arm_vlog_f32`（两 API 均已在 vendored 树、Makefile 未登记——见影响地图）。
3. **矩阵乘**：行主序 416 系数，`out[k] = Σ_j dct_coefs[k*32+j]·log_mel[j]`，自写双层 for（同 mel.c dot\_prod 累加模式）。

#### 五、资源预算（量化）

| 项     | 数值                                                                   |
| ----- | -------------------------------------------------------------------- |
| flash | const 表 416×4B=**1.62KB** + 代码 \~0.2KB ≈ **+1.8KB**                  |
| bss   | log 域静态缓冲 32×4=128B + freertos.c `s_mfcc13` 13×4=52B ≈ **+180B**     |
| CPU | 3200 logf/s + 41600 MAC/s + 3200 比较/s ≈ **<1% @168MHz**（SYSCLK 168MHz；logf 软实现百周期级，评审 M-3 修正：原文误写 84MHz） |
| 串口    | MFCC 行 \~90B ×1s 节流 = **+90B/s**（现 \~300B/s，预算内）                     |
