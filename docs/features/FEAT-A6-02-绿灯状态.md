## 3. 傻瓜式操作单（照做即可）

### 3.0 物品/工具清单（动手前先打勾，缺一不可）
- [ ] 核心板（A6-01 已通过）
- [ ] 绿灯 LED ×1 + **220Ω 限流电阻 ×1**
- [ ] 杜邦线 ×2、万用表（直流电压/电阻档）
- [ ] 5V 电源：电脑 USB 口 **或** 非快充 5V 适配器（**严禁手机快充头**）
- [ ] ST-Link（SWD 四线：SWDIO/SWCLK/GND/3.3V）+ `firmware\build_and_flash.bat`
- [ ] USB-TTL（CH340）+ SSCOM（115200，如需串口确认）

### 3.1 上电前检查（红线：全程断电，先拔电源再动线）
1. 绿灯接线：**PB1 → 220Ω 电阻 → LED 阳极（长脚）**；LED 阴极（短脚）→ GND。**禁止 LED 直接接 PB1 不串电阻**。
2. 万用表**电阻档**量 220Ω 电阻两端 → 期望 **≈220Ω**（记录数值：___ Ω）。
3. 断电状态下量 PB1 对 GND 电阻 → 应 **>100Ω**；接近 0Ω = 短路，回查接线。
4. 供电红线：只准电脑 USB / 非快充 5V 适配器；**严禁手机快充头**（烧板事故根因，见 A1-01）。
5. 万用表直流电压档：量 5V 引脚 → 期望 **4.8 ~ 5.2V**；量 3.3V 引脚 → 期望 **3.2 ~ 3.4V**（记录数值：___V / ___V）；不在范围 → 断电换电源，禁止继续。

### 3.2 上电基线观察（正常态）
1. 插电，观察绿灯：**正常应"常亮"**。
2. 若上电后绿灯灭 → 查 §3.4（故障标志误触发 / 实现方式/极性错）。

### 3.3 故障态验证（阶段 4 执行）
1. 记录故障标志触发方式：___（接口待定（需人确认），按阶段 1 确认结果填写）。
2. 触发**故障标志** → 绿灯**灭**（记录：灭 是/否）。
3. 恢复正常（清除标志）→ 绿灯重新**常亮**（记录：常亮 是/否）。
4. 结论记录：两态实测是否符合预期（是/否），未通过项写进执行日志。

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 绿灯完全不亮 | 220Ω 断路 / LED 极性反 / 输出未使能 | 断电查电阻与极性；查 TIM3_CH4/GPIO 配置 |
| 绿灯常亮不灭 | 故障标志未触发 / 灭逻辑未生效 | 查标志接口与映射；确认标志确实在变 |
| 上电即灭 | 故障标志误触发 / 默认态写错 | 查标志电平；确认默认=常亮 |
| 绿灯微亮 | 占空比过高 / 未串 220Ω | 确认串 220Ω；查占空比（参数待定（需人确认）） |
| 烧录失败 | ST-Link 四线/驱动 | 查 SWDIO/SWCLK/GND/3.3V；兜底 `firmware\flash_isp.bat`（HANDOFF §4.3） |
| 编译报错 | 工具链/路径问题 | 截图报错，查 `firmware\build.sh` 或 CI |
