## 3. 傻瓜式操作单（照做即可）

### 3.0 物品清单（动手前先打勾，缺一不可）
- [ ] 核心板（已通电正常，boot 三行可见）
- [ ] SHT30 模块 ×1
- [ ] 杜邦线（母对母）×4
- [ ] 万用表（直流电压档）
- [ ] 5V 电源：电脑 USB 口 **或** 非快充 5V 适配器（⚠️ **严禁手机快充头**，沿用 A1-01 §3.2 供电红线）
- [ ] USB-TTL（CH340）+ SSCOM 串口助手（115200）

### 3.1 接线（全程断电！先拔掉所有电源线再动线）
> ⚠️ 红线：SHT30 与 OLED 共用 I2C1 总线，**地址不得冲突**（SHT30=**0x44** 已由 pin_config.h 定义，与 OLED 0x3C 不冲突）；接线前确认模块额定电压。

| 顺序 | 从（SHT30） | 到（核心板） | 核对要点 | 完成 |
|------|-----------|------------|---------|------|
| 1 | VDD | **待定**（需人确认：常见 3.3V，以模块手册为准） | ⚠️ 先查额定电压再接，别超压 | ☐ |
| 2 | GND | GND | — | ☐ |
| 3 | SCL | PB6 | ⚠️ 共总线：SHT30 地址 **0x44** 与 OLED(0x3C) 不冲突（pin_config.h 已定义） | ☐ |
| 4 | SDA | PB7 | 同上 | ☐ |

### 3.2 上电前测量（红线：**先量再插电**）
1. 万用表拨到**直流电压 20V 档**，红笔接被测脚、黑笔接 GND。
2. 量核心板 **5V** 引脚 → 期望 **4.8 ~ 5.2V**（记录数值：______）
3. 量核心板 **3.3V** 引脚 → 期望 **3.2 ~ 3.4V**（记录数值：______）
4. ⚠️ 任一不在范围 → **断电，换电源，禁止继续**（沿用 A1-01 §3.2）。

### 3.3 上电 + 串口观察（阶段 4 执行）
1. USB-TTL 接核心板：TX↔RX **交叉**、GND 共地。
2. SSCOM 打开**设备管理器里看到的 COM 口**（不一定是 COM4），波特率 **115200**。
3. 按复位键，期望依次出现三行：`SoundDog boot OK` → `I2S_DRV_Init ret=0` → `I2S DMA started`。
4. 随后期望出现温湿度打印行（**格式待定需人确认**，如 `SHT30: temp=xx.x C humi=xx.x %RH`）。
   - 记录温度：___ °C　记录湿度：___ %RH
5. 数值应稳定（抖动容差待定需人确认）；恒定不变 → 查 §3.5。

### 3.4 行为验证（阶段 4 执行）
1. 对传感器**哈气 3 秒** → 湿度应明显上升（记录：___ %RH → ___ %RH）。
2. **手捂模块 10 秒** → 温度应明显上升（记录：___ °C → ___ °C）。
3. 两项变化成立 + §3.3 数值合理 = 采集链路通过；不成立 → 查 §3.5。

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 串口无温湿度行 | 接线错 / 命令错 | 查 §3.1 接线；确认 SHT30 地址 0x44（pin_config.h 已定）与测量命令（待定需人确认） |
| 打印恒 0 或乱码 | I2C 速率 / 上拉缺失 / 共总线冲突 | 确认地址与 OLED 不同；查板载上拉（待定）；速率按 CubeMX 默认（待定） |
| 温度恒定不变 | 未真正读取 / 传感器损坏 | 手捂验证；仍不变 → 换模块 |
| 湿度恒 100% 或 0 | 转换公式错误 / 接线虚 | 核对转换公式（待定需人确认）；重插线 |
| 接上 SHT30 后 OLED 显示异常 | 地址冲突 / SCL/SDA 接反 / 总线被拉死 | 断电检查 SCL↔PB6、SDA↔PB7；确认两器件地址不同 |
