### 3.1 采集正常特征数据（A3-04 串口输出 → 文件）
1. 上电，SSCOM 打开对应 COM 口（115200）。
2. 确认串口出现 boot 三行（`SoundDog boot OK` → `I2S_DRV_Init ret=0` → `I2S DMA started`）且能看到 13 维 MFCC 打印行。
3. 保持正常环境（安静/正常工况），采集足够帧数（样本量：待定（需人确认））（**记录实际帧数：___ 帧**）。
4. 保存为数据文件（**记录文件路径：______**）。
5. 抽查每行是否 13 个数：**期望 13 维**（记录实际维数：___ 维）。

### 3.2 运行 K-means（K=16）
1. 运行聚类脚本，参数 **K=16**（禁止改）。
2. 记录输出：**簇中心数：___（期望 16）**；每个中心维度：**___（期望 13）**。
3. 检查各簇样本数：**各簇样本数：___**（任一簇=0 → 空簇=样本不足，回 §3.1 补采）。
4. 固定随机种子保证可复现（**记录种子值：___**）。

### 3.3 导出正常模版

3. 与 A4-02 约定模版加载接口：**待定（需人确认）**。

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 串口无 13 维打印 | A3-04 未通过 / COM 口错 / 波特率错 | 确认 A3-04 状态；COM 以设备管理器为准；波特率 115200 |
| 行维数 ≠ 13 | 打印格式/分隔解析错 | 核对 A3-04 打印格式（待定（需人确认）），修正解析 |
| 空簇（某簇 0 样本） | 正常样本数不足 / 特征全雷同 | 补采更多帧；检查特征是否全 0（回 A1-02/A1-03 查链路） |
| 两次运行结果不一致 | 未固定随机种子 | 固定种子后重跑（记录种子值） |
| 模版数值全 0 / 巨大 | 采集时链路异常（BUG-002 取数/麦克风） | 回 A1-02/A1-03 查链路后重新采集 |
