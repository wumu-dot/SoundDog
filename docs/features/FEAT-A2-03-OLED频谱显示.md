### 1.1 核心目标（一句话）
> 把 A2-02 的 32 个频带幅度谱以柱状图实时显示到 0.96" SSD1306 OLED（I2C1），刷新 ~200ms。

### 1.4 关键参数与接口（权威：事实包 §3.6 A2-03 + §3.2 + PROJECT_PLAN §5.1）
- **OLED = I2C1**：PB6 SCL / PB7 SDA（`pin_config.h`：`OLED_I2C_SCL_PIN=GPIO_PIN_6`、`OLED_I2C_SDA_PIN=GPIO_PIN_7`、`OLED_I2C=I2C1`）。
- SSD1306 0.96"，**地址 0x3C**（`pin_config.h` `OLED_I2C_ADDR=0x3C`；0x3D 备用）。
- **32 频带柱状图**；**128 列每柱 4px**（128/32=4，算术推导）；柱高 = 能量对数归一化（父 FEAT）。
- **刷新 ~200ms（TaskDisplay）**：PROJECT_PLAN §5.1 —— TaskDisplay：Normal 优先级、堆栈 4096 字、周期 200ms。
- I2C1 与 I2S3 独立总线，不抢 I2S（PROJECT_PLAN 风险表：OLED 走 I2C 独立总线，不冲突）。

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| OLED 完全不亮 | 地址不对（0x3C/0x3D）/ 接线错 / VCC 供电问题 | 核对 `pin_config.h` 地址与 §3.1 接线；VCC 电压需人确认后重试 |
| 有反应但乱码/花屏 | 供电不足 / 接线接触不良 | 重插杜邦线；检查 GND；确认 VCC 电压 |
| 柱状图不变化 | 数据源（A2-02）无更新 / TaskDisplay 未创建 | 确认 TaskDisplay 已创建（PROJECT_PLAN §5.1）；用 A2-04 串口输出核对数据 |
| 柱高全满或全空 | 对数归一化基准错误 | 检查归一化基准（待定项需人确认） |
| I2S 音频断流 | OLED 意外占用 I2S3 总线 | 核对 OLED 走 I2C1（PB6/PB7）而非 I2S3；查 PROJECT_PLAN 风险表（I2C 独立总线不冲突） |
| 串口无输出/乱码 | TX/RX 未交叉 / COM 口错 / 波特率错 | 交叉接、看设备管理器、改为 115200 |
