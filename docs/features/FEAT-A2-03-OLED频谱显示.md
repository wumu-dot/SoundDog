### 1.4 关键参数与接口（权威：事实包 §3.6 A2-03 + §3.2 + PROJECT_PLAN §5.1）
- **OLED = I2C1**：PB6 SCL / PB7 SDA（`pin_config.h`：`OLED_I2C_SCL_PIN=GPIO_PIN_6`、`OLED_I2C_SDA_PIN=GPIO_PIN_7`、`OLED_I2C=I2C1`）。
- SSD1306 0.96"，**地址 0x3C**（`pin_config.h` `OLED_I2C_ADDR=0x3C`；0x3D 备用）。
- **32 频带柱状图**；**128 列每柱 4px**（128/32=4，算术推导）；柱高 = 能量对数归一化（父 FEAT）。
- **刷新 ~200ms（TaskDisplay）**：PROJECT_PLAN §5.1 —— TaskDisplay：Normal 优先级、堆栈 4096 字、周期 200ms。
- I2C1 与 I2S3 独立总线，不抢 I2S（PROJECT_PLAN 风险表：OLED 走 I2C 独立总线，不冲突）。

### 3.2 地址与初始化（阶段 3 执行）
1. 地址确认：`pin_config.h` `OLED_I2C_ADDR=0x3C`（0x3D 备用）。**记录实际使用地址：0x3C（I2C scan 实测应答，2026-08-29）**

### 3.3 频谱绘制与刷新（阶段 3/4 执行）
1. 数据源：A2-02 的 32 频带能量 `bands[32]`（**已实现：128 bins ÷ 4 bins/带 = 32 带，带内求和聚合，×100 整数**——原稿「256 bin/每带 8 bin」为旧稿笔误，以 A2-02 实现为准）。specTask 处理后写入全局显示快照 `spectrum_display_get()`，TaskDisplay 临界区拷贝读取（读写窗口 ~几 µs，冲突概率可忽略）。
2. 绘制布局：128 列 / 32 柱 = 每柱 4px（**3px 柱体 + 1px 间隙**，视觉更清晰）；柱高 = **整数对数归一化**：`h = 63 × ilog2(1+band) / ilog2(1+REF)`，REF=20000（×100 域）——1kHz 实测单 bin 162/100 量级、吹气峰 32768，对数域覆盖两档；基准可阶段 4 按实测微调。
3. 刷新：TaskDisplay 每 **200ms** 取快照 → 重绘 framebuffer → 页式 I2C 刷新（8 页 × 129B，400kHz 全屏 ≈25ms 阻塞，Normal 优先级可接受）。**记录实测刷新间隔：~200ms 量级（displayTask osDelay(200) 节拍 + 25ms 刷新阻塞；柱状图目视流畅无拖影，用户 2026-08-29 确认"会动"）**
4. 吹气/说话：柱状图柱高应随声音明显变化。**记录观察：✅ 柱状图实时跳动（用户 2026-08-29 确认"会动"）；串口侧 max 782→32768 跟随，peak_bin 1→7/10/22 宽带跳变**

### 3.4 A1 回归（阶段 4 执行，AC-02 证据）
1. SSCOM（115200）：boot 三行依次出现（`SoundDog boot OK` → `I2S_DRV_Init ret=0` → `I2S DMA started`）。**记录：✅ 2026-08-29 串口日志三行前缀按序出现，中间插 OLED init 2.16s（诊断期时序吻合）**
2. 吹气：`[n] max=xxxx` 仍明显变化（I2S3 采集未受 OLED 影响）。**记录读数范围：782 ~ 32768（含削波满幅；安静 ~1000，发声 3000~32768）**

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| OLED 完全不亮 | 地址不对（0x3C/0x3D）/ 接线错 / VCC 供电问题 | 核对 `pin_config.h` 地址与 §3.1 接线；VCC 电压需人确认后重试 |
| 有反应但乱码/花屏 | 供电不足 / 接线接触不良 | 重插杜邦线；检查 GND；确认 VCC 电压 |
| 柱状图不变化 | 数据源（A2-02）无更新 / TaskDisplay 未创建 | 确认 TaskDisplay 已创建（PROJECT_PLAN §5.1）；用 A2-04 串口输出核对数据 |
| 柱高全满或全空 | 对数归一化基准错误 | 检查归一化基准（待定项需人确认） |
| I2S 音频断流 | OLED 意外占用 I2S3 总线 | 核对 OLED 走 I2C1（PB6/PB7）而非 I2S3；查 PROJECT_PLAN 风险表（I2C 独立总线不冲突） |
| 串口无输出/乱码 | TX/RX 未交叉 / COM 口错 / 波特率错 | 交叉接、看设备管理器、改为 115200 |
