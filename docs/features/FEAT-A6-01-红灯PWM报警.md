## 3. 傻瓜式操作单（照做即可）

### 3.0 物品/工具清单（动手前先打勾，缺一不可）
- [ ] 核心板（A4 链路已通，能输出异常标志）
- [ ] 红灯 LED ×1 + **220Ω 限流电阻 ×1**
- [ ] 杜邦线 ×2、万用表（直流电压/电阻档）
- [ ] 5V 电源：电脑 USB 口 **或** 非快充 5V 适配器（**严禁手机快充头**）
- [ ] ST-Link（SWD 四线：SWDIO/SWCLK/GND/3.3V）+ `firmware\build_and_flash.bat`
- [ ] USB-TTL（CH340）+ SSCOM（115200，阶段 4 用）

### 3.1 上电前检查（红线：全程断电，先拔电源再动线）
1. 红灯接线：**PB0 → 220Ω 电阻 → LED 阳极（长脚）**；LED 阴极（短脚）→ GND。**禁止 LED 直接接 PB0 不串电阻**。
2. 万用表**电阻档**量 220Ω 电阻两端 → 期望 **≈220Ω**（记录数值：___ Ω）。
3. 断电状态下量 PB0 对 GND 电阻 → 应 **>100Ω**；接近 0Ω = 短路，回查接线。
4. 供电红线：只准电脑 USB / 非快充 5V 适配器；**严禁手机快充头**（烧板事故根因，见 A1-01）。
5. 万用表直流电压档：量 5V 引脚 → 期望 **4.8 ~ 5.2V**；量 3.3V 引脚 → 期望 **3.2 ~ 3.4V**（记录数值：___V / ___V）；不在范围 → 断电换电源，禁止继续。

### 3.2 上电基线观察
1. 插电，观察红灯：**正常应"灭"**（正常灭模式）。
2. 若一上电就闪/亮 → 查 §3.4（A4 标志误触发 / 默认状态错）。

### 3.3 三模式验证（阶段 4 执行；触发方式按 A4 接口，见阶段 1 确认结果）
1. 记录异常标志触发方式：___（接口待定（需人确认），按阶段 1 确认结果填写）。
2. 触发**异常标志** → 红灯**快闪**：记录闪动周期 ___ ms（期望值：待定（需人确认））。
3. 触发**警告标志**（若 A4 区分）→ 红灯**慢闪**：记录闪动周期 ___ ms（期望值：待定（需人确认））。

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 红灯完全不亮 | 220Ω 断路 / LED 极性反 / PWM 未使能 | 断电查电阻与极性；查 TIM3_CH3 配置与复用 |
| 红灯常亮不闪 | 模式映射未生效 / 标志未变化 | 查模式切换逻辑；确认 A4 标志确实在变 |
| 红灯微亮 | 占空比过高 / 未串 220Ω | 确认串 220Ω；下调占空比（参数待定（需人确认）） |
| 上电即快闪 | A4 标志误触发 / 默认态写错 | 查 A4 标志电平；确认默认=灭 |
| 烧录失败 | ST-Link 四线/驱动 | 查 SWDIO/SWCLK/GND/3.3V；兜底 `firmware\flash_isp.bat`（HANDOFF §4.3） |
| 编译报错 | 工具链/路径问题 | 截图报错，查 `firmware\build.sh` 或 CI |
