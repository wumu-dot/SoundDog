## 1. 总体目标与硬边界

### 1.1 核心目标（一句话）
> 在 A4-02 的 d_min 基础上加连续帧判决状态机：**连续 30 帧异常 → 报警**、**连续 60 帧正常 → 解除**，抑制瞬时误报/误解除。

### 1.2 地基触碰前置自检
- [x] 否 → 继续（App 层状态机，不碰底层库）

### 1.3 任务边界
| 类型 | 具体内容 |
|------|----------|
| 范围内（可改） | 帧计数状态机、报警/解除输出（串口打印必做；A6 灯/蜂鸣器接口预留） |
| 超出范围（禁止碰） | `firmware/Drivers/` HAL 底层库、A4-02 距离计算内部实现 |
| 外部依赖 | A4-02 通过（d_min 可用）、异常阈值（本 FEAT 先固化默认值：待定（需人确认）；A4-04 支持 RS485 下发） |

### 1.4 关键参数（事实包 §3，禁止自造）
- 判决计数：**连续 30 帧异常 → 报警**；**连续 60 帧正常 → 解除**（A4-03 事实，不可改）。
- 帧率参考：特征帧移 10ms=160 样（A3-01 事实）→ 若逐帧判决，30 帧≈300ms、60 帧≈600ms（实际判决节拍：待定（需人确认））。
- 报警输出：串口打印（本 FEAT 必做）；A6-01 红灯快闪 / A6-03 蜂鸣器异常断续报警（A6 未开始，仅预留接口，接线与启用：待定（需人确认））。
- 阈值来源：A4-02 d_min 阈值（A4-04 支持 RS485 下发）。
