## 1. 总体目标与硬边界

### 1.1 核心目标（一句话）
> 通过 RS485 下发异常检测的**阈值**（A4-02 d_min 阈值）与**帧数**（A4-03 的 30/60），使检测参数可在线调整，无需改代码重烧。

### 1.2 地基触碰前置自检
- [x] 否 → 继续（App 层 USART3 收发，不碰底层库）

### 1.3 任务边界
| 类型 | 具体内容 |
|------|----------|
| 范围内（可改） | USART3 RS485 接收/解析、参数更新逻辑（阈值/帧数）、范围校验、回环自检 |
| 超出范围（禁止碰） | `firmware/Drivers/` HAL 底层库、A4-02 距离计算内部、A4-03 状态机内部 |
| 外部依赖 | A4-03 通过、TTL-RS485 模块（3.3V/SP3485）、PC 端 USB-TTL + TTL-RS485 模块、参数持久化（重启后保持依赖 A7-03 Flash，未实现，待定（需人确认）） |

### 1.4 关键参数（事实包 §3，禁止自造）
- 硬件：**RS485 = USART3 + TTL-RS485 模块（3.3V/SP3485）**；A/B 双线对接；**DE/RE 视模块类型**：有 DE/RE 引脚则 GPIO 控制方向，自动收发型免接（A5-01 事实）。
- 可调参数：**阈值**（A4-02 d_min 阈值）、**帧数**（A4-03：30 帧异常报警 / 60 帧正常解除）。
- 帧协议：A5-02 约定**帧头 0xA5 / 帧尾 0x5A / CRC16**（A5 未开始，实际下发帧格式：待定（需人确认））。
- 参数默认值/取值范围/参数 ID：待定（需人确认）。
- 参数持久化：重启后是否保持，依赖 A7-03 Flash 存模版参数：待定（需人确认）。
