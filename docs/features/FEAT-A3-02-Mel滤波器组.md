### 1.4 关键参数（事实包 §3.6 A3-02 + §3.1，禁止自造）

* 滤波器数量：**32 个三角 Mel 滤波器**。

* 频率覆盖：**300Hz \~ 8kHz**（第 1 个滤波器起点 300Hz、第 32 个终点 8kHz）。注：8kHz = Fs/2（奈奎斯特），最后一带贴边，属事实包给定值，如实实现。

* Mel 刻度（标准定义，实现按此计算，**禁止手工编造边界频率表**）：`mel(f) = 2595·log10(1 + f/700)`。

* 输入：A3-01 加窗帧（400 样）→ 需 FFT 转频域；**FFT 点数：512 补零**（A3-01 阶段 2 已定稿：400 样拷入 512 缓冲、高 112 样补零；A3-01 §1.5）。

* 采样率 **Fs = 16kHz**（A1-04 核实后为准）。

* 输出：**32 维 Mel 能量**。

* 打印格式（阶段 2 定稿）：`MEL b=<峰值带号> m=<m0>,<m1>,...,<m31>`（×1 整数截断，BANDS 逗号风格，\~1s 一行节流）。

#### 一、已确认决策（人确认"按推荐"）

| 决策项        | 定稿                                                                                                              | 来源/理由                               |
| ---------- | --------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| Mel 表生成    | **本地复刻官方公式**（scripts/gen\_mel\_table.py，算法逐字对齐 CMSIS-DSP v1.14.4 Scripts/mfccdata.py 的 melFilterMatrix()，已跑通出表） | 决策 A；numpy/scipy 已装，参数全可配，产物直接 C 数组 |
| 计算节流       | **每帧都算**（100 帧/s，CPU \~12%）                                                                                     | 为 A4 连续帧特征直接就绪；实测预算见第五节             |
| 打印格式       | `MEL b=<峰值带> m=32 维逗号串`，1s 节流                                                                                   | BANDS 风格，保留完整分布                     |
| **是否重复加窗** | **不重复加窗**——A3-01 帧已汉明加窗；`arm_mfcc_f32` 源码 L84-90 自带窗+归一化，**整体调用会窗叠窗**，故不整体调官方函数、只复用其分步算法                        | 官方源码核实（R27）                         |
| 归一化        | 不做 1/absmax 归一化（输出原始 Mel 能量；对数域偏移留给 A3-03 按官方 L134 `+1e-6` 再做）                                                  | 分 FEAT 边界                           |
| FFT 实例     | mel.c 内部**独立** `arm_rfft_fast_instance_f32`（512 点），不碰 fft.c/fft\_run（单消费者格局零触碰）                                 | fft.h 头注释约束                         |
| 触发判据       | App 层轮询 `mfcc_frame_count()` 变化才调 mel\_process（128 样块喂入与 160 样出帧不通约）                                            | A3-01 同款机制                          |

#### 二、数据流

```
I2S DMA → audio_queue(128样) → specTask：
  spec_process(pcm256) ──────────────→ SPEC/BANDS/OLED（A2 链路，不动）
  mfcc_feed(pcm256) → 400 样加窗帧 ──→ [新增] 帧计数变化？
                                        └→ mel_process(mfcc_last_frame())
                                             400→512 补零 → rfft(独立实例)
                                             → mag[257] → 32×arm_dot_prod_f32
                                             → mel_out[32] → 串口 MEL 行(1s 节流)
```

#### 三、模块接口（BSP/mel.h）

| API | 签名                                                                      | 职责                                                    |
| --- | ----------------------------------------------------------------------- | ----------------------------------------------------- |
| 初始化 | `int mel_init(void)`                                                    | rfft 512 实例初始化（幂等，任务入口调用）                             |
| 处理  | `int mel_process(const float32_t frame400[400], float32_t mel_out[32])` | 加窗帧→512 补零→rfft→幅度谱→32 维 Mel 能量；返回 0 成功；**A3-03 的输入** |

#### 四、核心机制（无先例可抄部分）

1. **稀疏 Mel 表**（复刻官方）：`mels = linspace(mel(300), mel(8000), 34)`；三角滤波 = `max(0, min(上斜率, 下斜率))`；每带只存 `filtPos/filtLen/非零系数`（totalLen=473），运行时 `arm_dot_prod_f32(mag+filtPos[i], coefs+off, filtLen[i])`——与官方 `arm_mfcc_f32` L120-131 逐字同构。
2. **512 补零边界**：`s_in[0..399]=帧, [400..511]=0`；rfft 输出解包 `tmp[512]=tmp[1], tmp[1]=0` → 复数\[257] → `arm_cmplx_mag_f32(tmp, mag, 257)`（显式 257，边界自证）。
3. **公式等价性**：官方 `1127·ln(1+f/700)` ≡ 规格 `2595·log10(1+f/700)`（2595/log10(e)=1127.0），AC-01 判据无冲突（R28 核查通过）。

#### 五、资源预算（R29 第 3 件）

| 项              | 数值                                                                    | 判据                                    |
| -------------- | --------------------------------------------------------------------- | ------------------------------------- |
| flash（const 表） | +1.91KB（filtPos 128B + filtLen 128B + coefs 473×4B=1892B）+ 代码 \~1.5KB | text 现 161204，余量大                     |
| RAM（bss 静态）    | +\~5.3KB（s\_in 512×4 + s\_tmp 514×4 + s\_mag 257×4 + s\_mel 32×4）     | bss 现 91032 / 192KB，余量足               |
| CPU            | 512 rfft ≈1.0ms + mag 257 + 473 MAC ≈ **1.2ms/帧 × 100 帧/s ≈ 12%**     | specTask 现负载 \~6%，合计 \~18%，168MHz 可承载 |
| 串口带宽           | MEL 行 \~180B × 1 行/s = **+180 B/s**                                   | 现 \~1KB/s @115200，承载无虞                |
| 栈              | 零大数组上栈（全静态）；printf 路径不变                                               | specTask 2KB 栈现状已含 printf             |

#### 七、防御设计

* 全程 float32 域计算（无符号陷阱教训）；Mel 能量峰值 \~4e6 < int32 上限（×1 打印安全，A3-01 评审 Minor#2 的饱和问题在此口径下不触发）

* mag 除 DC/Nyquist 外恒非负；dot\_prod 输入有界（filtLen ≤ 34）无溢出路径

* mel\_process 输入 NULL / 帧计数未增时 App 层不调用（防御性检查在 App 挂接处）

* NaN 兜底：若 mag 出 NaN（理论无路径），打印前钳位（A3-01 §3.4 速查表已有排查项）
