### 1.1 核心目标（一句话）
> 对 A3-01 加窗帧做 FFT 后，经 32 个三角 Mel 滤波器（300Hz~8kHz）映射为 32 维 Mel 能量，供 A3-03 Log 能量 + DCT-II 使用。

### 1.4 关键参数（事实包 §3.6 A3-02 + §3.1，禁止自造）
- 滤波器数量：**32 个三角 Mel 滤波器**。
- 频率覆盖：**300Hz ~ 8kHz**（第 1 个滤波器起点 300Hz、第 32 个终点 8kHz）。注：8kHz = Fs/2（奈奎斯特），最后一带贴边，属事实包给定值，如实实现。
- Mel 刻度（标准定义，实现按此计算，**禁止手工编造边界频率表**）：`mel(f) = 2595·log10(1 + f/700)`。
- 输入：A3-01 加窗帧（400 样）→ 需 FFT 转频域；**FFT 点数：待定（需人确认）**（400 样非 2 的幂：补零/截断策略未定，沿用 A3-01 结论）。
- 采样率 **Fs = 16kHz**（A1-04 核实后为准）。
- 输出：**32 维 Mel 能量**。

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 32 维全部为 0 | 输入帧全 0 / FFT 未接 / 取数掩码错 | 回溯 A3-01 加窗帧输出；查 BUG-002 取数 |
| 输出维度 ≠32 | 滤波器个数实现错 | 核对 32 个三角滤波器 |
| 峰值带号与预期不符 | 采样率不是 16kHz / FFT 点数换算错 | A1-04 核实采样率；按所选 FFT 点数重算 bin |
| 高频带能量恒为 0 | 滤波器高频端点贴奈奎斯特（8kHz=Fs/2）/ 声源无高频 | 属事实包给定边界，如实核对；换宽带声源（吹气）复测 |
| NaN / 溢出 | float32 / FPU | 查 `-mfpu=fpv4-sp-d16 -mfloat-abi=hard` |
| 编译链接失败 | Makefile 漏加源（BUG-002 教训） | C_SOURCES 加 `dsp/mel.c` 重编 |
