## 1. 总体目标与硬边界

### 1.1 核心目标（一句话）
> 板端实时计算当前 13 维 MFCC 特征与 16 个正常模版的距离（欧氏/余弦），**取最小距离 d_min** 输出，为 A4-03 连续帧判决提供输入。

|------|----------|
| 范围内（可改） | 距离计算模块、d_min 输出接口（供 A4-03）、阈值常量（暂定，A4-04 使其可配置） |
| 超出范围（禁止碰） | `firmware/Drivers/` HAL 底层库、A4-01 模版生成（PC 端）、A4-03 防抖判决 |
| 外部依赖 | A4-01 通过（16 个 13 维模版可用）、A3 通过（板端 13 维 MFCC 特征流） |

### 1.4 关键参数（事实包 §3，禁止自造）
- 模版库：**16 个簇中心**（A4-01 输出，每个 13 维向量）。
- 距离度量：**欧氏距离 / 余弦距离**（A4-02 事实；默认用哪种：待定（需人确认））。
- 判决量：**取最小距离 d_min**（A4-02 事实，不可改）。
- 异常阈值：d_min 判定阈值 **待定（需人确认）**；A4-04 支持 RS485 下发。
- 特征帧率参考：帧移 10ms=160 样（A3-01 事实）；判决节拍见 A4-03。

### 3.4 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| d_min 恒为 0 或全部相等 | 模版未加载 / 特征恒 0 | 确认模版导入（方式待定（需人确认））；回 A3 查特征流 |

| d_min 为 NaN | 除零（余弦距离分母=0） | 余弦分母为 0 时的处理：待定（需人确认），退回阶段 3 说明 |
