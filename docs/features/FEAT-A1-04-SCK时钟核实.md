### 3.1 接线（断电操作）
> 注：通道号是标签，用哪几个通道都行（本机 Logic 1 界面显示 Channel 4~7）。接完可按波形形状自检：最快方波=SCK、慢方波=WS、数据突发=SD。

| 逻辑分析仪 | 接到核心板 | 核对要点 |
|-----------|-----------|---------|
| 任选通道①（如 CH4） | PB3（SCK） | 时钟线 |
| 任选通道②（如 CH5） | PA4（WS） | 声道选择 |
| 任选通道③（如 CH6） | PB5（SD） | 数据线 |
| GND | GND | 必须共地 |

### 3.2 抓取
1. 打开 Saleae Logic 1.2.17 → 顶部应显示 **[Connected]**（未识别则看资料夹《手把手教...手动安装教程.docx》装驱动）。
2. 左下 Capture：采样率 **24M**（本机 8 通道上限，实测可选"24 M Samples"；≥23 倍过采样），采样时长数秒。
3. 核心板上电，点绿色 **Start**，等采集完成自动停止。
4. 滚轮放大 CH0 波形，拖时间标尺量 SCK 一个完整周期（ΔT 显示在测量栏）。
5. （可选交叉验证）右侧 **Analyzers +** → 添加 **I2S** 解码器 → 绑定 SCK/WS/SD 通道 → 自动标出 32-bit 帧。

### 3.3 读数与判定
- **SCK 频率**：实测值 = 1 / 周期 = **___ MHz**；期望 1.024MHz，合格范围 0.973 ~ 1.075。
- **WS 周期**：应 = 64 个 SCK（对应 Fs=16kHz）：**___ 个 SCK**。
- 两项都合格 → ✅ 通过，README 遗留关闭。
- 若 SCK ≈ **2.048MHz**（2 倍）→ 进入 §3.4 修正。

### 3.4 修正流程（仅当实测 ~2.048MHz）
1. 打开 `firmware/soundDog/soundDog.ioc`（CubeMX）。
2. 调整 I2SDIV 或 PLLI2S 分频，使 SCK 回到 1.024MHz（参考 `docs/CubeMX_I2S3配置详解.md` 时钟推导）。
3. 重新生成代码（确认手动代码都在 USER CODE 区间，见 BUG-001 教训）。
4. `firmware\build_and_flash.bat` 重烧 → 回到 §3.3 复测。

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 抓不到任何波形 | 探头没夹牢 / 未上电 / 通道接错 | 检查杜邦线接触；确认板子供电 |
| SCK 显示失真/毛刺 | 采样率不足 | 采样率必须 ≥8M，用 16M |
| WS 无周期性 | 未在采集 I2S（麦克风未工作） | 确认 A1-02 链路在跑 |
| 频率 ~2.048MHz | I2SDIV/PLLI2S 配置问题 | 按 §3.4 修正 |

## 4. 验收标准（12 条）

### 功能验收
- [x] AC-01 逻辑分析仪实测 SCK = 1.024MHz ±5%（0.973~1.075MHz），Fs=16kHz
  **✅ 通过（2026-08-28 Saleae Logic 1.2.17 实测，24MHz/1s）**：
  - SCK（CH3，PB3）：f = 1MHz（T=1µs，标注分辨率 ±4%，真值 0.977~1.024µs，与设计 1.024MHz 兼容）
  - WS（CH4，PA4）：f = **16kHz 精确命中**（T=62.5µs，50% 占空比，标准 I2S 帧同步形态）
  - 交叉验证：WS 周期 ÷ SCK 周期 = 62.5µs ÷ 1µs ≈ 62~64 SCK/帧，与 32-bit×2 声道结构自洽
  - **结论：Fs=16000Hz 无误，README"SCK 疑似 2 倍"遗留正式证伪关闭**
- [x] AC-02 向后兼容（不破坏 A1-02 已通过链路；若改配置，重烧后 A1-02 复测通过）
