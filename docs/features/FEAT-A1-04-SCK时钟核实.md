## 3. 傻瓜式操作单（照做即可）

### 3.0 物品/工具清单
- [ ] 逻辑分析仪 zave 24M/8ch
- [ ] PulseView（sigrok）软件（免费，官网下载）
- [ ] 杜邦线 ×4（CH0/CH1/CH2/GND）
- [ ] 核心板（A1-02 已通过）

### 3.1 接线（断电操作）
| 逻辑分析仪 | 接到核心板 | 核对要点 |
|-----------|-----------|---------|
| CH0 | PB3（SCK） | 时钟线 |
| CH1 | PA4（WS） | 声道选择 |
| CH2 | PB5（SD） | 数据线 |
| GND | GND | 必须共地 |

### 3.2 抓取
1. 打开 PulseView → 采样率选 **24M**（≥4 倍过采样）。
2. 添加 3 个通道（CH0/CH1/CH2）。
3. 核心板上电，开始采集 ~10ms。
4. 放大波形，用光标测量 SCK 一个周期。

### 3.3 读数与判定
- **SCK 频率**：实测值 = 1 / 周期 = **___ MHz**；期望 1.024MHz，合格范围 0.973 ~ 1.075。
- **WS 周期**：应 = 64 个 SCK（对应 Fs=16kHz）：**___ 个 SCK**。
- 两项都合格 → ✅ 通过，README 遗留关闭。
- 若 SCK ≈ **2.048MHz**（2 倍）→ 进入 §3.4 修正。

### 3.4 修正流程（仅当实测 ~2.048MHz）
1. 打开 `firmware/soundDog/soundDog.ioc`（CubeMX）。
2. 调整 I2SDIV 或 PLLI2S 分频，使 SCK 回到 1.024MHz（参考 `docs/CubeMX_I2S3配置详解.md` 时钟推导）。
3. 重新生成代码（确认手动代码都在 USER CODE 区间，见 BUG-001 教训）。
4. `firmware\build_and_flash.bat` 重烧 → 回到 §3.3 复测。

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 抓不到任何波形 | 探头没夹牢 / 未上电 / 通道接错 | 检查杜邦线接触；确认板子供电 |
| SCK 显示失真/毛刺 | 采样率不足 | 采样率必须 ≥8M，用 24M |
| WS 无周期性 | 未在采集 I2S（麦克风未工作） | 确认 A1-02 链路在跑 |
| 频率 ~2.048MHz | I2SDIV/PLLI2S 配置问题 | 按 §3.4 修正 |
