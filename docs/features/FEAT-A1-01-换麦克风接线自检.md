## 3. 傻瓜式操作单（照做即可）

### 3.0 物品清单（动手前先打勾，缺一不可）
- [ ] INMP441 模块 ×1（原装芯片、已焊排针）
- [ ] 杜邦线（母对母）×6
- [ ] 4.7kΩ 电阻 ×1（SD 上拉，建议加）
- [ ] 万用表（直流电压档）
- [ ] 5V 电源：电脑 USB 口 **或** 非快充 5V 适配器（**严禁手机快充头**）
- [ ] USB-TTL（CH340）+ SSCOM 串口助手（阶段 4 用）

### 3.1 接线（全程断电！先拔掉所有电源线再动线）
按顺序接线，**每接完一根在 ☐ 打勾**，接错一根就返工：

| 顺序 | 从（INMP441） | 到（核心板） | 核对要点 | 完成 |
|------|-------------|-------------|---------|------|
| 1 | VDD | 3.3V | ⚠️ 千万别接 5V！ | ☐ |
| 2 | GND | GND | — | ☐ |
| 3 | L/R | GND | ⚠️ 必接！悬空 = 无声（之前故障根因之一） | ☐ |
| 4 | SCK | PB3 | — | ☐ |
| 5 | WS | PA4 | — | ☐ |
| 6 | SD | PB5 | 加 4.7kΩ 上拉至 3.3V | ☐ |

### 3.2 上电前测量（红线：**先量再插电**）
1. 万用表拨到**直流电压 20V 档**，红笔接被测脚、黑笔接 GND。
2. 量核心板 **5V** 引脚 → 期望 **4.8 ~ 5.2V**（记录数值：______）
3. 量核心板 **3.3V** 引脚 → 期望 **3.2 ~ 3.4V**（记录数值：______）
4. ⚠️ 任一不在范围 → **断电，换电源，禁止继续**（上次 5V=3.1V 导致启动异常/复位循环）。
5. （断电状态下）万用表拨**电阻档**，量 INMP441 的 VDD 对 GND → 应 **>100Ω**；接近 0Ω → 接线短路，回 §3.1 查线。

### 3.3 上电观察
1. 插上电源。
2. 5 秒内手摸 INMP441 表面：**微温 = 正常**；**发烫 → 立即断电**，大概率 VDD 接到 5V 或短路，回 §3.1 查线。

### 3.4 串口确认（阶段 4 执行；本次若只做接线可跳过，留到 A1-02）
1. USB-TTL 接核心板：TX↔RX **交叉**、GND 共地。
2. SSCOM 打开**设备管理器里看到的 COM 口**（不一定是 COM4），波特率 **115200**。
3. 按复位键，期望依次出现：`SoundDog boot OK` → `I2S_DRV_Init ret=0` → `I2S DMA started`。
4. 对麦克风吹气：`[n] max=xxxx` 数值应**明显变化**（如几百 ↔ 几万）。

### 3.5 故障速查表（出问题先查这里）
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 量 5V 只有 ~3V | 快充头 / 电源带不动 | 换非快充 5V 适配器或电脑 USB 口 |
| 模块发烫 | VDD 接错 5V / 短路 | 立即断电，重查 §3.1 表 |
| 串口完全无输出 | TX/RX 没交叉 / COM 口选错 / GND 未共地 | 交叉接、看设备管理器、共地 |
| 输出乱码 | 波特率不对 | 改为 115200 |
| 只出 boot 前几行就停 | 供电不稳 | 量 5V/3.3V，换电源 |
| 数据恒 `0000FFFF` | L/R 悬空 / SD 高阻 / 模块损坏 | 确认 L/R→GND；SD 加 4.7kΩ 上拉；仍如此 → 模块坏，联系换货 |
| 吹气数值不变 | 麦克风损坏 / 焊点虚 | 轻敲 PCB 听变化；无反应 → 换模块 |
