### 1.4 关键参数（事实包 §3.6 A3-04 + §3.1，禁止自造）
- **串口打印 13 维 MFCC**，与已知信号特征吻合（事实包 A3-04）。
- 已知信号源：A2-02 的 **1kHz 正弦**测试信号 / 吹气（宽带噪声）/ 静音。
- 期望特征（定性，记录实测）：
  - 静音 → 13 维整体能量低；
  - 1kHz 纯音 → 低频 Mel 带对应系数明显（能量集中于低频）；
  - 吹气/噪声 → 高频带分量出现，与纯音分布明显不同。
- **MFCC 数值范围：待定（需人确认）**（A4 用 K-means(K=16) 建模时确定正常范围；本 FEAT 只记录实测值，不做阈值判定）。
- 打印节流：**待定（需人确认）**（可选参考 A2-04 的 ~200ms 节流，事实包 §3.6 A2-04）。
- 采样率 **Fs = 16kHz**（A1-04 核实后为准）。

### 3.6 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 13 维恒为 0 | A3-03 输出全 0，链路断裂 | 回溯 A3-03 / A3-02 / A3-01 各段打印定位 |
| 静音与吹气差异小 | 环境噪声大 / 增益过高 / 麦克风问题 | 换安静环境；核对 A1 采集（A1-02 max 变化） |
| 1kHz 纯音无反应 | 声源频率/音量/连接问题 | 换扬声器/提高音量；确认 A2-02 曾用该声源验证通过 |
| 打印乱码 | 波特率 / TX↔RX 未交叉 / GND 未共地 | 改 115200；交叉接；共地 |
| 数值含 NaN / INF | A3-03 Log 防护缺失 | 退回 A3-03 处理 |
| 三种信号两两差异都不明显 | 数值范围异常（如溢出饱和） | 记录原始值，退回 A3-02/A3-03 核对算法参数 |
