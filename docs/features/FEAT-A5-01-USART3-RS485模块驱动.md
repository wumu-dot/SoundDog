### 1.4 关键参数与接口（事实包 §3 + pin_config.h，禁止自造）
- **USART3 引脚**：TX=**PD8**、RX=**PD9**（`RS485_TX_PIN` / `RS485_RX_PIN`）；波特率 **115200**（`RS485_UART_BAUD`）。
- **EN 方向控制脚**：**PD11**（`RS485_DE_PIN`，pin_config.h 注释"DE/RE 方向控制"）。
- **模块引脚（用户已确认丝印）**：**EN / VCC / A / B / GND×2 / RXD / TXD**（SP3485，3.3V，半双工）。
  - 模块 **RXD** ← MCU **PD8（USART3_TX）**（TTL 交叉：MCU 发 → 模块收）
  - 模块 **TXD** → MCU **PD9（USART3_RX）**（模块发 → MCU 收）
  - 模块 **EN** ← MCU **PD11**：**高=发送 / 低=接收**（方向控制）
  - 模块 **A / B** ← RS485 差分总线（本 FEAT 回环测试可 A-B 对接；A5-03 两模块对接）
- **回环验收**：**回环可收发**（事实包 A5-01）。
- **现状事实**：pin_config.h 标注 USART3 "预留，待 CubeMX 配置"；`soundDog.ioc` 当前外设列表（DMA/FREERTOS/I2S3/NVIC/RCC/SYS/USART1）**不含 USART3** → 阶段 1 必须核实。
- **待定（需人确认）**：rs485 驱动文件名；回环验证方式若与 §3 不符按现场记录差异。

### 3.1 接线（全程断电！先拔掉所有电源线再动线）
**红线**：模块 VCC **只准接 3.3V**（SP3485 为 3.3V 器件，接 5V 可能烧模块）；A/B 差分端子不得与电源/GND 短路；EN 空闲必须为 0（接收态）。按顺序接线，**每接完一根在 ☐ 打勾**：

| 顺序 | 从（RS485 模块） | 到（核心板） | 核对要点 | 完成 |
|------|-----------------|-------------|---------|------|
| 1 | VCC | 3.3V | ⚠️ 严禁 5V！ | ☐ |
| 2 | GND（任一个） | GND | 必须共地 | ☐ |
| 3 | RXD | PD8（USART3_TX） | ⚠️ 交叉：MCU 发 → 模块收 | ☐ |
| 4 | TXD | PD9（USART3_RX） | ⚠️ 交叉：模块发 → MCU 收 | ☐ |
| 5 | EN | PD11 | GPIO 方向控制：高=发送 / 低=接收 | ☐ |
| 6 | A | A（回环测试：A-B 对接时接 B 端 A） | 本 FEAT 回环可暂不接 | ☐ |
| 7 | B | B（同上） | 本 FEAT 回环可暂不接 | ☐ |

> 回环说明：半双工自发自收需要 RS485 侧有回环路径（A-B 对接或模块内部回环）。若模块 A/B 悬空无法回环 → 用杜邦线将本模块 A 与 B 短接（或按 §3.2 步骤1 记录的模块手册方式）。

### 3.4 故障速查表（出问题先查这里）
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 完全无回环数据 | RXD/TXD 接反 / EN 未接或接反 / 波特率不对 | 核对 §3.1 表；波特率 115200；确认 PD11 已接 EN |
| 收到乱码 | 波特率不符 / 杜邦线接触不良 / 未共地 | 改 115200；重插线；确认 GND 共地 |
| 回环无数据且 A/B 悬空 | 差分侧无回环路径 | A-B 短接（或按模块手册回环方式）后重试 |
| 发送后收不到回环 | 发送完成未切回接收态（EN 恒高） | 确认 TC 标志后 EN=0 |
| 编译失败/链接失败 | Makefile 漏加源文件（BUG-002 教训） | `Makefile` C_SOURCES 补 rs485 源文件后重编 |
| 烧录连不上 | ST-Link 四线/驱动 | 查 A1-02 §3.1 兜底：`firmware\flash_isp.bat`（BOOT0+USART1） |
| 回环方式与上述不符 | 模块手册有特定回环接法 | 以模块手册为准，记录差异到执行日志（待定项） |
