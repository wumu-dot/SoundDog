### 3.2 正常轮询时序（阶段 4 执行）
1. 启动轮询（主节点发轮询帧，含从地址）。
2. 期望：从节点在**超时内**回复（回复帧含从地址 + 数据）。
   记录：从"收到轮询"到"发出回复"耗时：____
3. 连续轮询 100 轮：期望 100 轮全部成功、无总线冲突。
   记录：成功轮数：___/100；冲突次数：___；超时次数：___
4. 半双工红线：主发完轮询帧后**立即转接收态**；从回复期间主不得再发。

### 3.3 从节点不主动发验证（阶段 4 执行）
1. 主节点停止轮询，让总线空闲。
2. 观察从节点 60s（时长可现场调整，记录实际值）：期望**从节点不发任何字节**。
   记录：观察时长：____；发现主动发送：是 / 否
3. 若从节点主动发 → 违反"节点不主动发"，退回阶段 3 查监听状态机。

### 3.4 无应答场景（阶段 4 执行；验证主节点不挂死）
1. 人为制造无应答：拔掉从端模块电源（或从端不响应）。
2. 主节点继续轮询：期望主节点**超时后重试（按 §3.1 次数）→ 记录失败 → 继续下一轮，不挂死**。
   记录：单轮无应答处理耗时：____；连续 10 轮无应答后主节点状态：正常 / 挂死
3. 恢复从端供电：期望下一轮轮询自动恢复成功。
   记录：恢复后首轮结果：成功 / 失败

### 3.5 故障速查表
| 现象 | 可能原因 | 处理 |
|------|---------|------|
| 轮询冲突乱码 | 两端同时发送（主重发过快 / 从主动发） | 核对半双工错开（§3.2 步骤4）；查从节点是否违规主动发 |
| 轮询超时无回复 | 从地址不符 / 帧格式错（A5-02） / 波特率 | 核对 §3.1 地址与 A5-02 §3.1 帧格式；两端 115200 |
| 从节点主动发数据 | 监听状态机缺陷，违反"节点不主动发" | 退回阶段 3，修复从节点状态机（只收不发） |
| 主节点挂死 | 超时/重试未实现 | 退回阶段 3，补超时与重试逻辑 |
| 恢复供电后仍失败 | 从节点未回监听态 / 主节点状态错乱 | 两端复位重连，重跑 §3.2 |
