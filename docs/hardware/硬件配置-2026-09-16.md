## 1. 供电与共地（R40，硬红线）

- **供电源**：独立 DC 电源模块（3.3V/5V/12V 多路，配 220V 适配器）
  - `电源模块 5V → STM32 板 5V 输入`（板上 AMS1117 稳压 → 3.3V）
  - `电源模块 GND → STM32 GND`
- **共地闭合链（四端两两导通 ≈0Ω，通电前必须验证）**：
  ```
  电源模块GND → STM32_GND → RS1(MAX3485)_GND → USB转RS485适配器_GND
  ```
  - STM32→RS1→USB 适配器为飞线/面包板短接（近距 115200 可接受，用独立短飞线）。
  - RS1 有两个 GND 脚，任一处共用即可。

### 通电前判据（每条必过，缺一步就停，沿用 R36/R37）
1. 通断档验证四端 GND 两两导通 **≈0Ω**。
2. **RS1/MAX3485 的 VCC = STM32 板载 3.3V**（不接电源模块 5V，也不用电源模块自带 3.3V 输出，避免两套参考打架）。
3. 通电量 `5V≈5V`、`STM32 3.3V≈3.3V`。
4. 未全部合格前**禁止任何 A/B 总线或 5V 相关自检**（上次 ESP32 烧板即跳过此步：5V 倒灌击穿 3.3V 轨，3.3V-GND 实测 7.8Ω）。

## 2. STM32 ↔ RS1(MAX3485) 接口（USART3，已核实标准）

| STM32 引脚 | 功能 | → 模块丝印 | 芯片功能 | 说明 |
|---|---|---|---|---|
| PD8 | USART3_TX（AF7） | → **RXD** | ≈DI | 发送（TTL 3.3V），模块 RXD=接收输入（模块收 MCU 数据） |
| PD9 | USART3_RX（AF7） | ← **TXD** | ≈RO | 接收（TTL 3.3V），模块 TXD=发送输出（模块发 MCU 数据） |
| PD11 | GPIO 推挽输出（高发/低收） | → **EN** | ≈DE/RE | RS485 方向控制 |
| VCC | 3.3V（板载，见 §1） | → 模块 **VCC** | — | 不是 5V |
| GND | STM32_GND | → 模块 **GND** | — | 共地 |

- **模块实物丝印以 §3 为准**：`RS485 V2.0` 板，左列 `EN / VCC / RXD / TXD / GND`，右列 `GND / A / B`。
- 🔴🔴 **本表是【唯一正确接法】—— 曾有过一版接反的表，务必别看反**（2026-09-29 审查官加注）：
  - ⛔ **接反版**（已证不通）：`TXD → PD8`、`RXD → PD9` ⇒ 适配器读回为空、`RO` 恒 0.15 V
  - ✅ **正确版（本表）**：`TXD → PD9`、`RXD → PD8` ⇒ 打通，收 `01 03 02 02 58 B8 DE`
  - ⚠️ **那份接反的表还在**：`桌面\报告\目前进度\souddog\SoundDog-RS485链路排查测试-2026-09-17.md` §2
    —— **该文档整篇已作废、已就地标红，严禁作为接线依据引用。**
- ⚠️ 命名易混（2026-09-21 实证）：模块丝印 **TXD=RO=模块输出 → 接 MCU RX(PD9)**；**RXD=DI=模块输入 → 接 MCU TX(PD8)**（TTL 交叉）。照 MCU 视角接线会反（详见 §3 🔴 命名更正）。
- 参数：USART3 115200-8N1、无流控；FreeModbus 从站地址 0x01，**0 基址**（R34）。
- A/B 差分侧只对总线（适配器 COM5 / ESP32），与 STM32 USART 引脚无关。

## 3. RS485 模块丝印 / 引脚布局（实物：`RS485 V2.0`）

> **模块型号丝印（2026-09-28 用户提供实物照片确认）**：板面印 **`RS485` / `V2.0`**，板上有 4 个 LED 焊位。
> **逐针丝印（2026-09-28 用户逐针复述确认，两列不对称布局）**：

```
      左列（上→下）              右列（上→下）
        EN  ────────────────      GND
       VCC  ────────────────      A
       RXD  ────────────────      B
       TXD  ────────────────
       GND  ────────────────
       └── 5 针 ──┘              └─ 3 针 ─┘
```

| 模块丝印 | 列/位置 | 对应芯脚/作用 | 已确认接线/值 |
|---|---|---|---|
| **TXD** | 左列第 4 | **发送输出（≈RO，模块向 MCU 发）** | → STM32 **PD9**（USART3_RX）✅ 2026-09-21 实测确认 |
| **RXD** | 左列第 3 | **接收输入（≈DI，模块从 MCU 收）** | ← STM32 **PD8**（USART3_TX）✅ 2026-09-21 实测确认 |
| **EN** | 左列第 1 | 发送/接收使能（≈DE/RE） | ← STM32 **PD11**（高发低收） |
| **VCC** | 左列第 2 | 供电 | = STM32 板载 **3.3V** |
| **GND** | 左列第 5 | 地 | = STM32 GND（共地链） |
| **GND** | 右列第 1 | 地 | = STM32 GND（共地链，**与左列 GND 同网**） |
| **A** | 右列第 2 | RS485 差分正（485A/A+） | → 对端 485A |
| **B** | 右列第 3 | RS485 差分负（485B/B-） | → 对端 485B |

> 🔴 **2026-09-28 记录更正（重要）**：旧版本节记的是
> `max3485 | VCC | EN | A | B | RX | TX | GND | GND`（8 脚线性排布、丝印为 `RX`/`TX`、`A/B` 在中段）。
> **实物核对后确认该记法有误** —— 实物是 **`RS485 V2.0` 板、两列不对称布局**，
> 丝印为 **`RXD`/`TXD`**（带 D 后缀），**`A`/`B` 在右列**，且**未记"V2.0"板型**。
> ⇒ **本节已按实物更正。旧"max3485"记法作废。**
> ⚠️ **教训**：丝印这类"必须对实物"的信息，**禁止从旧文档转述**；
> 凡引用必回查本节的实物记录（判据 D / T21）。

> 🔴 **命名更正（2026-09-21 实测）**：本表原按「MCU 视角」把 TXD 标为数据输入(≈DI)、RXD 标为接收输出(≈RO)，**导致接线反了**——按旧表 TXD←PD8、RXD←PD9 实测收不到应答（RO 恒 0.15V 高阻误诊）。
> **正确语义**：模块丝印 **TXD = 芯片 RO（模块"发送"给 MCU）→ 接 MCU RX(PD9)**；模块丝印 **RXD = 芯片 DI（模块"接收"来自 MCU）→ 接 MCU TX(PD8)**（TTL 交叉）。
> **实证**：对调为 TXD→PD9、RXD→PD8 后，主站适配器收到合法应答 `01 03 02 02 58 B8 DE`，链路打通。
> ⚠️ ② VCC 已确认存在，接板载 3.3V（非 5V，R36），未确认供电脚位前别上电独立供电。
> ⚠️ ③ **本模块 A/B 排针是否直连芯片 6/7 脚、芯片本体引脚是否引出，均【未测】**（见 `09-17:57` 最后分叉）。

## 4. USB 转 RS485 适配器（COM5）

- 端子（Lesminer 型/LES26）：**5V | GND | GND | 485B | 485A**
- 5V 来自电脑 USB(VBUS)，仅作供电参考；GND 必须进入 §1 共地链。
- 指示灯：电源 / TXD / RXD。
- ⚠️ 烧板教训（R36/R37）：**禁止在多板系统里用「B 碰 5V」自检法**，未验共地时 5V 会倒灌击穿 3.3V 逻辑芯片。
- 判据：A/B 空闲应有差分（A、B 对 GND 有明显压差、A−B 非零）；A≈B≈1.67V 为漂浮电平 = 共地缺失。

## 5. 逻辑分析仪（R41，通道映射）

- **硬件端口**：8 个数据通道 **硬CH1~硬CH8** + **CLK** + **GND**；软件侧 **软CH0~软CH7**（8 通道）。
- **固定错位映射（用户 2026-09-16 确认，✅实测）**：**硬CHn ↔ 软CH(n-1)**，即 n=1..8：

| 硬CH | 软CH |
|---|---|
| CH1 | CH0 |
| CH2 | CH1 |
| CH3 | CH2 |
| CH4 | CH3 |
| CH5 | CH4 |
| CH6 | CH5 |
| CH7 | CH6 |
| CH8 | CH7 |

- **CLK**：外部时钟输入，本测试**不用**（内部时钟采样即可）。
- **GND**：公共地参考，测试时务必与板 GND 相连。

**抓取规则**：
1. 采样率 **≥1MHz**（115200，建议 ≥2MHz）。
2. 抓 **TTL 侧** PD8(USART3_TX) / PD9(USART3_RX)，按上表「硬↔软」映射在软件挂 **UART 8N1 解码器**（3.3V TTL，勿用 RS485 差分解）。
3. 接线例：硬CH1→板PD9，则在软件对 **软CH0** 挂解码器 = PD9。**以软件通道为准，别管丝印编号**。
