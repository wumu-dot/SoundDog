## 2. 【P0】P2-1 修法重做（审查报告第三节，🔴）

### 2.1 现状
`App/main.c:104-117`：`_write` 内 `taskENTER_CRITICAL()` 包住 `HAL_UART_Transmit(&huart1,...,100)`。

### 2.2 问题（量化已由审查官给出）
- 屏蔽范围：优先级数值 ≥5 的全部中断（SysTick=15、PendSV=15、USART3=5、SPI3=5、I2S DMA1_Stream2=5）
- 量级：RX 探针单行 ~778B → **67ms 屏蔽**；BANDS 单行 ~224B → **19ms 屏蔽**
- 后果 ①：tick 冻结（SysTick 被屏蔽）
- 后果 ②：I2S DMA 半缓冲 16ms < BANDS 单行 19ms → 音频溢出丢帧风险（🔴推断，需实测）
- 后果 ③：`_write` 死循环（临界区内 `HAL_GetTick` 冻结 → 100ms 超时永不成立 → 永久自旋）

### 2.3 处置方案（审查官建议，执行方选型）
**首选**：`taskENTER_CRITICAL` → `osMutex`（互斥信号量，只做任务级串行化、不屏蔽中断）
**次选**：USART1 输出队列化到 specTask 单点发送（贴合 BUG-20260829-003「单写者」本意）

### 2.4 验证判据（R25）
- [ ] 构建 0 error / 0 warning；size 与声明一致
- [ ] COM4 日志：MBSlavePollTask 启动期 printf 与 specTask 统计输出**无交错、无乱序**
- [ ] 音频链路实测（如可测）：A3-02 100 帧/s 规整网格无丢帧
- [ ] 无新探针/无新诊断残留（探针台账核对）

### 2.5 决策门
- 方案选型（osMutex vs 单点发送）**由用户裁决**
- 是否随本次一并处理第 9 节注释改写，由用户裁决

## 3. 【P0】RS485 链路补测（审查报告 §5.1.4 + §5.1.1 预测）

### 3.1 目的
在「换模块 / 换芯片」决策前，把断点从「RS1 模块内部」进一步收窄，并验证审查官的**可证伪预测**。

### 3.2 补测清单（一次量完，110 波特率发包）
| 序 | 测量 | 判据 | 指向 |
|---|---|---|---|
| 1 | 芯片 8 脚 VCC 对地 | ≈3.3V | 模块供电走线/焊盘断 |
| 2 | 芯片 5 脚 GND 对地 | ≈0V | 模块地走线断 |
| 3 | 芯片 2/3 脚 RE/DE 对地 | 低=接收态 | 使能走线断/EN 未到芯片 |
| 4 | 芯片 1 脚 RO 对地电阻 | 无短路 | RO 被短到地（0.15V 恒低来源） |
| 5 | 芯片 6/7 脚 A/B 差分（发包） | 摆动 | 芯片收到 vs 模块 A/B 走线断 |
| 6 | **PD9 对地电压** | 恒低≈0.1~0.2V | 验证 RXNE 持续触发/put_index 饱和预测 |

### 3.3 审查官预测（§5.1.1）——测完对照
- 预测①：PD9 恒低 → RXNE 持续触发 → `put_index` 约 22ms 饱和到 256
- 预测②：⚠️ **换好模块后必须先复位 STM32 再测**，否则首次 IDLE 会打印 `RX[256]:` + 256 个 `00` 并回灌总线 → 污染结果

### 3.4 决策门
- 补测结果出来后，**换芯片 vs 整块换模块**由用户拍板
- 换件后必须执行「先复位再测」协议

## 4. 【P1】测试报告两处更正（审查报告 §5.1.1 / §5.1.2）

### 4.1 更正①（5.1.1）：探针无输出与 RO 恒低是同一因果链
- 原文「STM32 的 USART3 硬件层面未收到字节」→ 改为「**PD9 被 RO 拉死恒低，USART3 无空闲边界（IDLE 永不成立），探针线程从未被唤醒**」
- 依据：IDLE 成立条件 = 收到字节且线路回空闲高；RO 恒低 → 永无 IDLE

### 4.2 更正②（5.1.2）：断点措辞降级
- 原文「断点定位：MAX3485 芯片 RO 输出侧」→ 改为「**断点已收窄到 RS1 模块内部（端子→芯片→RO），尚未在 RO 输出级与模块走线之间二选一**」（R25）

### 4.3 更正③（5.1.3）：−6.35V 不作健康差分证据
- 原文「差分信号强达 RS1 ✅」→ 改为「**−6.35V 更像未端接线路振铃/共模问题，不能作为差分健康证据**；须同一参考地量 A对地/B对地/A−B 复测」

### 4.4 验证判据
- [ ] 更正后报告不再自相矛盾、不越级（对照 R25）
- [ ] 两份受影响文档（测试报告）同步修正
