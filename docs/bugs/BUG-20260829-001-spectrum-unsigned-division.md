# 频谱输出恒定假峰 bin1 + 幅度超数学上限 + 输出冻结

- **Bug ID**：BUG-20260829-001
- **严重等级**：P1-严重（核心功能输出全错，但无崩溃/死机）
- **发现日期**：2026-08-29
- **修复日期**：2026-08-29
- **关联 FEAT**：FEAT-A2-02

## 现象描述
A2-02 硬件验证阶段，串口 `SPEC` 行出现三联异常：
1. `peak_bin` 恒为 1（环境变化也纹丝不动）
2. `mag` ≈ 3020500/100，超 256 点 FFT 幅度数学上限（13800/100）200 倍
3. 输出值冻结（mag 末 3 位几乎不变），而 `[n] max=` 证明输入数据在正常变化

## 复现步骤
1. 烧录 A2-02 阶段 3 固件（含 `mean /= FFT_LEN` 写法）
2. SSCOM 115200 观察串口
3. 环境音/吹气扰动麦克风，观察 SPEC 行数值不变、max 行正常变化

## 根因分析
`mean /= FFT_LEN` 中宏 `FFT_LEN` 定义为 `256u`（unsigned），C 语言隐式转换规则将有符号负数 `mean` 转为 unsigned 参与除法：真实均值 -918 变为 4294967296-918 再除 256 → 16776298（恰为 2^24-918）。诊断版日志铁律：真实均值为负 → 打印值 = 真实值 + 2^24；均值为正 → 完全正常（100% 命中 6 样本）。

## 修复方案
`mean /= (int32_t)FFT_LEN;` 显式带符号除法（spectrum.c）。类型陷阱排查复排全部 int/unsigned 混用点，无第二个同类陷阱（阶段 5 评审确认）。

## 影响文件
- `firmware/soundDog/Src/dsp/spectrum.c`（去直流均值除法）

## 验证方式
修复后烧录同一固件：假峰 bin1、幅度超限、输出冻结三现象全部消失；1kHz 实麦验证 peak_bin=16（30+ 样本零漂移，理论值精确命中）、mag=160~172/100、noise=3~4/100、ratio=40~55。闭环取证：修复前 m0=70543 与 -512×Σwin=70543 分毫不差（均值偏移量可精确预测）。

**验证条件**（必填，R25）：
- 硬件/环境：INMP441 新麦克风（A1-03 验证过的良品）+ 手机 1kHz 纯音近距离播放，SSCOM 115200，固件 text=153748
- 验证的因果链：已验证"输入扰动→输出跟随"（1kHz 播放→bin=16 稳定命中；安静/环境/吹气三档 SPEC 输出显著区分），非"数值非零"级验证
- 结论级别：功能正常

## 通用教训（提炼至 lessons_summary）
宏带 `u` 后缀（如 `256u`）与可能为负的有符号变量混算（除法/取模）时，负值隐式转 unsigned——去直流均值/移动平均/差分等中间量可能为负的场景，运算前必须显式 `(int32_t)` cast；或改在 float 域计算（多数开源参考实现的做法）。
